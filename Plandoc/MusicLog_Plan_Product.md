# MusicLog — 기획서
## 서비스 기획 및 제품 정의

---

## 1. 서비스 개요

### 슬로건
> **"인스타는 너무 넓고, 내 음악 취향은 너무 소중하니까."**

### 한 줄 소개
> **인스타에 올리기엔 사소하고, 혼자 듣기엔 아까운 음악의 순간을 가까운 친구들과 15초로 공유하는 앱.**

### 컨셉
**MusicLog**는 음악 스트리밍 서비스를 일상적으로 사용하는 유저들이, 자신이 좋아하는 음악의 특정 순간을 가까운 친구들과 공유하는 **폐쇄형 음악 소셜 플랫폼**이다.

사용자는 곡 전체가 아니라 특정 구간을 선택하고, 그 구간에 대한 감상평을 짧게 남겨 소규모 그룹 안에서 공유한다.

MusicLog는 음원을 저장하거나 편집하지 않는다.  
대신 곡 정보, 플랫폼 source, 시작/종료 타임스탬프, 감상 텍스트를 저장하여 **Music Moment Card** 형태로 공유한다.

## 2. 핵심 문제 정의

### 기존 음악 공유의 문제

```text
- 인스타그램은 너무 공개적이어서 음악 취향을 올리기 부담스럽다.
- 카카오톡으로 음악 링크만 보내면 어느 구간이 좋은지 전달하기 어렵다.
- 스트리밍 앱은 감상에는 좋지만, 친구들과 "이 구간이 좋다"를 공유하는 소셜 경험은 약하다.
- 음악 리뷰 커뮤니티는 무겁고, 일상적인 음악 감정 공유에는 진입장벽이 높다.
```

### MusicLog의 해결 방향

> **MusicLog는 사용자가 좋아하는 음악의 특정 순간을 타임스탬프와 감상평으로 기록하고, 가까운 친구들과 공유하는 폐쇄형 음악 Moment 서비스다.**

## 3. 핵심 타겟

### 1차 타겟

```text
- Spotify Premium 사용자
- 음악을 자주 듣는 사람
- 친구에게 특정 구간을 추천하고 싶은 사람
- 음악 취향을 공개 SNS보다 좁은 관계 안에서 공유하고 싶은 사람
```

### 한국 시장 확장 타겟

```text
- YouTube Music / YouTube 사용자가 많은 국내 음악 리스너
- 카카오톡 기반 초대 그룹에서 음악을 공유하는 사용자
```

### 비핵심 타겟

```text
- 음악을 가끔만 듣는 라이트 유저
- 별도 음악 스트리밍 서비스를 거의 사용하지 않는 사람
- 광고가 포함된 무료 재생 경험만 사용하는 사용자
```

## 4. 핵심 가치

### 4.1. 심리적 해방감
- 공개 SNS가 아닌 소규모 그룹 중심 공유
- 음악 취향을 평가받는 부담 감소
- "친한 사람에게만 보여주는 음악 감정 기록" 제공

### 4.2. 빠른 공유
- 곡 선택 → 구간 선택 → 한 줄 감상 작성 → 그룹 공유

### 4.3. 짧은 감상
- 곡 전체가 아니라 15~30초 구간 중심
- 친구가 추천한 "그 부분"만 빠르게 감상
- 리액션과 짧은 답장을 통해 가벼운 소통 유도

### 4.4. 폐쇄형 관계
- 카카오톡 초대 링크 기반 그룹
- 연락처 전체 동기화보다 낮은 개인정보 부담
- 그룹장 승인 기반 입장 요청 가능

## 5. 핵심 UX 흐름

```text
친구가 올린 음악 Moment 클릭
→ 광고나 큰 이동 없이 15~30초 구간 감상
→ 리액션 / 답장
→ 다음 Moment로 이동
```

이 경험이 자연스럽게 구현되어야 MusicLog의 서비스 가치가 생긴다.

## 6. Music Moment 구조

### 핵심 개념

MusicLog의 Moment는 음원 파일이 아니라 **타임스탬프 기반 공유 객체**다.

```text
Moment =
곡 정보
+ 플랫폼 source
+ 시작/종료 시간
+ 감상 텍스트
+ 공개 범위
```

### Moment Card 예시

```text
🎧 Not Afraid - Eminem
01:12 ~ 01:32

"여기서 훅 들어오는 순간 진짜 다시 멘탈 잡힘."

[듣기]
[리액션]
[답장]
```

### Moment 만료 처리 정책

```text
- expires_at 도달 시 피드에서 숨김 처리 (Soft Delete)
- DB에서 즉시 삭제하지 않음 (리액션/답장 데이터 보존 목적)
- 만료된 Moment에 달린 리액션/답장은 본인 기록 페이지에서만 조회 가능
- 24시간 Music Story(Phase 3) 도입 전 이 정책을 확정한다
```

## 7. 그룹 초대

### 핵심 방향

연락처 전체 동기화보다 **카카오톡 초대 링크 기반 그룹 초대**를 우선한다.

### 그룹 생성 플로우

```text
1. 그룹 만들기
2. 그룹 이름 설정
   예: 새벽 감성방 / 힙합 얘기방 / 출퇴근 플리방
3. 그룹 공개 방식 설정
   - 초대받은 사람만
   - 링크 가진 사람만
   - 승인 후 입장
4. 카카오톡으로 초대 링크 공유
5. 초대받은 사용자는 입장 요청
6. 그룹장이 승인
```

### 초대 링크 구현 방식

```text
MVP (Option A): 단순 URL 복사/공유
  - 카카오 로그인 불필요, 구현 단순
  - 일반 딥링크 또는 웹 링크 형태

Phase 3 (Option B): 카카오톡 메시지 커스텀 (카드형, 이미지 포함)
  - 카카오 로그인 필요, Kakao SDK 연동 필요
  - 더 풍부한 초대 경험 제공
```

### 초대 메시지 예시

```text
나 MusicLog에서 음악 공유방 만들었어 🎧
인스타에 올리긴 좀 애매한데 같이 듣고 싶은 구간들 여기 올리려고ㅋㅋ

들어올래?
[초대 링크]
```

## 8. 주요 기능

### 8.1. Spotify-First MVP 핵심 기능

```text
- 회원가입 / 로그인
- Spotify 계정 연동
- 현재 재생곡 가져오기
- Spotify 곡 검색
- 곡 선택
- 15~30초 구간 선택
- Moment Card 생성
- 그룹 생성
- 카카오톡 초대 링크 (MVP: 단순 URL)
- 그룹 피드
- 리액션
- 짧은 답장
- Spotify source 기반 재생 또는 외부 앱 열기 fallback
```

### 8.2. Music Story (Phase 3)

24시간 후 사라지는 휘발성 음악 공유 기능이다.

```text
- 24시간 후 자동 만료
- 그룹별 공개 범위 설정
- 이모지 리액션
- 짧은 답장
- 스와이프형 탐색 UI
- 터치 기반 재생
```

### 8.3. Deep Archive / Music Magazine (Phase 4)

Music Moment가 가벼운 숏폼이라면, Deep Archive는 오래 남기는 음악 기록 공간이다.

```text
- 곡/앨범 단위 장문 리뷰
- 그룹 또는 전체 공개
- 댓글
- 추천
- 아카이브 페이지
```



## 11. 유사 서비스 분석

### MULOG
개인 음악 일기 / 월간 통계 및 캘린더 기반 기록 중심.  
MusicLog는 개인 기록보다 가까운 친구들과 특정 음악 구간을 공유하는 폐쇄형 소셜 경험에 초점을 둔다.

### Pinply
음악 스트리밍과 추천이 결합된 소셜 서비스. 곡/플레이리스트 단위 공유에 가깝다.  
MusicLog는 "15~30초 음악 순간"과 "폐쇄형 그룹 공유"에 초점을 둔다.

### Plorer
음악 하이라이트 공유와 가까운 유사 앱으로 추정 (구체적 정보 별도 검증 필요).  
MusicLog는 24시간 Music Story, 카카오톡 초대 기반 소규모 그룹, YouTube feasibility validation을 차별점으로 둔다.

## 12. 차별화 포인트

1. **공개 SNS가 아닌 폐쇄형 음악 소셜** — 가까운 사람들과 음악 취향을 공유하는 안전지대
2. **곡 전체가 아니라 특정 순간 공유** — 사용자가 좋아하는 특정 구간과 감정을 함께 공유
3. **타임스탬프 기반 공유** — 음원을 저장/편집하지 않고 플랫폼 source와 시작/종료 시간만 저장
4. **Spotify-first 현실적 MVP** — 구현 가능성이 높은 Spotify로 핵심 제품 경험을 먼저 검증
5. **YouTube 리스크를 정면으로 검증** — 본개발 전 별도 검증 단계를 통해 한국 시장 확장 가능성 판단
6. **카카오톡 초대 기반 그룹** — 국내 사용자에게 익숙한 초대 방식으로 초기 그룹 형성

## 15. 최종 제품 정의

> **MusicLog는 음악의 특정 순간을 타임스탬프와 감상평으로 기록하고, 가까운 친구들과 공유하는 폐쇄형 음악 소셜 플랫폼이다. Spotify 기반 MVP로 핵심 경험을 먼저 검증하고, YouTube 재생 UX가 검증될 경우 국내 시장 확장을 추진한다.**

> **친구에게 보내고 싶은 음악의 "그 15초"를 가까운 사람들과 공유하는 음악판 셋로그.**
